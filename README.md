🔐 NekDek Auth System

A full-stack authentication system built with Flask, MongoDB, and JWT featuring secure login, OTP-based email verification, and password reset.

---

🚀 Live Demo

- 🌐 Frontend: https://nek-dek-auth.vercel.app/login.html
- ⚙️ Backend: https://nekdek-auth.onrender.com

---

✨ Features

- User Signup & Login
- Email OTP Verification
- JWT Authentication
- Password Hashing
- Forgot/Reset Password
- Protected Routes

---

🧠 Tech Stack

- Backend: Flask, MongoDB
- Frontend: HTML, TailwindCSS, JS
- Deployment: Render, Vercel

---

⚙️ Setup

git clone https://github.com/your-username/nekdek-auth.git
cd backend
pip install -r requirements.txt
python app.py

---

🔐 Environment Variables

MONGO_URI=your-mongodb-uri
JWT_SECRET_KEY=your-secret
MAIL_USERNAME=your-email
MAIL_PASSWORD=your-app-password

---

📡 API

- POST "/api/auth/signup"
- POST "/api/auth/verify-otp"
- POST "/api/auth/login"
